# Contributing to AuraTunnel

Issues, reproducible bug reports, security reports, documentation corrections, and design discussion are welcome.

Code contributions are not automatically accepted. AuraTunnel uses a public noncommercial license together with separately negotiated commercial licenses. To preserve that model, do not submit a pull request containing code until the maintainer has confirmed the contribution terms in writing. A separate contributor agreement may be required before the pull request can be merged.

By merely opening an issue or pull request, you do not transfer copyright and the maintainer does not promise to merge, distribute, or commercially license your contribution.

Never submit:

- real VPN node credentials, subscription URLs, UUIDs, passwords, certificates, or API tokens;
- private provisioning profiles, signing certificates, `.p12` files, Apple API keys, or App Store Connect credentials;
- user traffic captures, DNS histories, connection logs, or personal information;
- third-party code that you do not have the right to contribute.

Security issues that would expose credentials, bypass the tunnel boundary, leak traffic, or affect user privacy should be reported privately to **silas980729@gmail.com**, not posted in a public issue.

All contributions must preserve third-party license notices and clearly identify modified third-party files.
